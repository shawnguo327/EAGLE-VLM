# Pre-EAGLE pilots (2026-10-30)
Code and reports of the pilots that preceded EAGLE-VLM, kept for provenance (data, model outputs and the venv stay on bjserver,
`/media/shawn/C/papers/VLM/{urban-judge-20261030,place-pulse-2.0}`).
- `place-pulse-2.0/`: Place Pulse 2.0 pairwise perception pilot with open VLM judges (prepare / run / summarize).
- `urban-judge-20261030/pp/`: Place Pulse judge variants (sample, multi-image, ranking, thinking) and analyses.
- `urban-judge-20261030/traj/`: trajectory-judging pilot.
Place Pulse was later judged a marginal dataset for the main claims; the EAGLE-VLM work moved to mainstream MLLM judge benchmarks.
